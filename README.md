# ⌨️ JavaScript Key Code Viewer

A simple web utility that displays the JavaScript key code and relevant event information when a key is pressed. Useful for developers working with keyboard interactions in JavaScript apps.

## 🔍 Features

- Displays the **key code** of the pressed key (e.g., `87`)
- Shows detailed event data:
  - `event.key`: Logical value of the key (e.g., `w`)
  - `event.code`: Physical location code (e.g., `KeyW`)
  - `event.keyCode`: Numeric code (deprecated but shown for reference)
- Useful tips and notes about keyboard event handling
- Clean and responsive UI

## 🧰 Built With

- **CSS**
- **JavaScript**
